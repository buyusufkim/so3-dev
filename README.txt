SO3 Event Poster Patch v1

Ekran kaydında siyah görünen iki video posterini düzeltir.

Değiştirilecek dosyalar:
- gomeda-vadisi-yuruyusu/video/01-poster.webp
- mobilite-grup-dersi/video/01-poster.webp

Posterler gerçek kaynak videolarından alınmış karelerdir.
Gomeda: doğal vadi/yürüyüş sahnesi.
Mobilite: salon içi grup mobilite sahnesi.

MP4 dosyalarına dokunmayın. Sadece poster WebP dosyalarını overwrite edin.
